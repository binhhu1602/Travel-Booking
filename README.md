# Travel Booking – Layout Lab

Ứng dụng Flutter 1 file minh họa bố cục linh hoạt và xử lý overflow qua màn hình chi tiết khách sạn.

- Code: [lib/main.dart](lib/main.dart)
- Giải thích và kịch bản demo: [GIAI_THICH.md](GIAI_THICH.md)

## Chạy

```bash
flutter run -d chrome
```

Hoặc dán nội dung `lib/main.dart` vào [DartPad](https://dartpad.dev). Vạch sọc overflow chỉ hiện ở debug mode.

## Kiểm thử

```bash
flutter test
```
